Application Operation & User Guide

Welcome to the Team Status Tracker App documentation dashboard. Expand the collapsible headers below to learn how each tool works and what key metrics to look out for.

1. Workspace & Attendance Capture Entry

The core panel on the left allows managers to add or update transactional status logs for individual agent entities.

  • Tracking Date & Name: Assigns the context frame. Names autocomplete against the verified workforce datalist.
  • Present Mode: Exposes fields for tracking operational leakages like Overbreaks and Tardiness in minute segments.
  • On Leave Mode: Hides running loss intervals and reveals dropdown selections for mapping standard leave profiles (SL, VL, VTO) alongside decimal duration days tracking.
  • Rest Day Mode: Safely isolates active staff roster tags from infraction tracking for designated weekly off days.
2. Live Stream Monitor & Form Controls

The dashboard table acts as a real-time reactive canvas rendering logged rows for the targeted date input context frame.

  • Clicking "View" inside the stream transfers tracking properties back to the workspace control panel, shifting layout focus into an interactive modification loop.
  • Buttons dynamically unlock based on context rules, allowing administrators to execute single row modifications or transaction deletion tasks.
3. Dashboard Analytics & Infographics Cards

The top row cards and distribution progress trackers are evaluated instantly as you record data parameters:

  • Active Pool of Agents: Total number of absolute tracking records present in the local cache.
  • Cumulative Tardiness & Overbreaks: Running summary computations displaying metrics in minute units. Higher figures draw purple or red hazard highlighting markers.
  • Daily Breakdown Distribution & Pool Coverage: Visually maps staffing presence ratios across the day's total operational footprint. Indicates workforce coverage efficiency.
4. System Analytical & Compliance Tools

Advanced metrics modules provide managers or team leaders with proactive workforce health analysis insights:

  • Agent Behavioral Pattern Trend Monitor: Summarizes an agent's cumulative tracking exceptions. Generates decision support indicators based on repetitive behavioral patterns.
  • Compliance Notification Dashboard: Flags agents crossing standard operations parameters. Displays dynamic provisional alerts indicating when automated human resources Notice to Explain (NTE) logs are triggered.
  • Performance & Losses Analytics: Tracks a rolling 7-day view of log activity patterns alongside historical metric leakage metrics.
5. System Resilience & Data Persistence Tips

Keep these performance rules in mind during long-term tracking use:

  • Data is stored offline in your browser session via sessionStorage.
  • Session storage holds data during hard reloads and refreshes. Perform regular data backups using the CSV Export button within the Master Logs module before ending your browser session.
