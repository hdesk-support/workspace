Dashboard Monitoring Guide

1. Online Masterfile Fetching & Manual Upload

This web dashboard automatically fetches the latest attendance-masterfile.csv hosted in your repository on startup.

Manual Override Option:

If you need to analyze an uncommitted local dataset, click the Upload Updated CSV button in the footer bar. Custom uploaded files persist in your local browser cache until purged.

2. Real-Time View & Excel Filtering

Use the global navigation control panel headers to step backward or forward along your calendar track timeline view matrix. Clicking into the Master Logs View dashboard opens an instant querying search window engine built to look up values identically to spreadsheet filtering models.
